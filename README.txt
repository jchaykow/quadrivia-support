Quadrivia public support/privacy pages

Upload index.html, icon.png, style.css, support/ and privacy/ to the web root.
Target routes: /support/ and /privacy/. Serve over HTTPS. No backend or build step.
Contact: support@quadrivia.co

Publish only this site directory, not the iOS repository, question bank, build outputs, or signing files.
After publication, verify both public routes and configure QuadriviaSupportURL and QuadriviaPrivacyPolicyURL in Quadrivia/Info.plist.
